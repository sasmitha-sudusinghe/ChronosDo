## ✨ Features

- **Notion-Inspired UI:** Clean, distraction-free aesthetic with smooth typography and block-based card layouts.
- **Dynamic Header:** Real-time clock, current date display, and customizable daily quotes/mood banner.
- **Task Management:** Add, tag, prioritize, filter, edit, and cross off work to-dos with real-time completion tracking.
- **Habit & Day Tracker:** Track daily routines (e.g., Deep Work, Hydration, Reading) with quick-increment counters.
- **Daily Journal Block:** Auto-saving notes section for quick thoughts, daily reflections, or meeting logs.
- **Dark / Light Mode:** Instant toggle between off-white light mode and slate dark mode.
- **Zero Backend Required:** All data is stored locally in your browser via `localStorage` for privacy and instant performance.
